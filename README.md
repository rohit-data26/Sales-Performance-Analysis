# Sales-Performance-Analysis
Sales performance Analysis using Excel
Project Overview:- This project analyzes sales data using Microsoft Excel. It includes data analysis,Pivot,Charts, and a dashboard to understand sales performance.
Project Objectives:-(a) Analyze sales performance for 2024 and 2025. (b) Compare sales across different years. (c) Identify sales trend and patterns. (d) Present a key  information through a dashborad.
Tools Used:- (a) Microsoft Excel 
             (b) Pivot Table
             (c) Charts and Data Visualization
